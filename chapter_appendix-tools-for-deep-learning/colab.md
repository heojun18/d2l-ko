# Google Colab 사용하기
:label:`sec_colab`

저희는 :numref:`sec_sagemaker`와 :numref:`sec_aws`에서 AWS에서 이 책을 실행하는 방법을 소개했습니다. 또 다른 옵션은 Google 계정이 있는 경우 [Google Colab](https://colab.research.google.com/)에서 이 책을 실행하는 것입니다.

Colab에서 어떤 절의 코드를 실행하려면, :numref:`fig_colab`에 표시된 것처럼 `Colab` 버튼을 클릭하기만 하면 됩니다.

![Colab에서 어떤 절의 코드 실행하기.](../img/colab.png)
:width:`300px`
:label:`fig_colab`


코드 셀을 처음 실행하는 경우, :numref:`fig_colab2`와 같은 경고 메시지를 받게 됩니다.
"RUN ANYWAY"를 클릭하여 무시하시면 됩니다.

!["RUN ANYWAY"를 클릭하여 경고 메시지 무시하기.](../img/colab-2.png)
:width:`300px`
:label:`fig_colab2`

다음으로, Colab은 이 절의 코드를 실행할 수 있도록 인스턴스에 연결해 줍니다.
구체적으로 말씀드리면, GPU가 필요한 경우
Colab은 자동으로 GPU 인스턴스에 연결을 요청합니다.


## 요약

* Google Colab을 사용하여 이 책의 각 절 코드를 실행할 수 있습니다.
* 이 책의 어떤 절에서든 GPU가 필요한 경우 Colab은 GPU 인스턴스에 연결을 요청합니다.
